The single scroll screen puts sync state before setup, permissions, and the separate empty webhook test. It uses native Views and system sans. No dependency, Gradle, manifest, schema, transport, health reader, or containment coordinator change is required.

`SyncStatusDisplay.Snapshot` carries read-only display inputs. OFF, waiting, paused, blocked, and unknown have separate labels and symbols. The model never infers health delivery from an old success string. Only the exact persisted containment acceptance string acknowledges an empty test. The test card explains that acceptance does not confirm health delivery. Progress has no invented batch or chunk counts. The existing last-success timestamp remains a separately labeled historical value.

`Settings.syncEnabled`, stored under the existing encrypted key and defaulting false, is the sole sync preference. Programmatic binding suppresses the switch listener. Explicit ON schedules the existing `SyncWorker` periodically. That worker can only record OFF or PAUSED for health work. Explicit OFF cancels health schedules. [`MainActivity.onCreate`](../app/src/main/java/dev/healthbridge/MainActivity.kt) binds saved state and refreshes without scheduling or pausing work. [`SyncControl.save`](../app/src/main/java/dev/healthbridge/SyncControl.kt), called by the settings save listener in `MainActivity.onCreate`, reschedules the periodic worker with the saved interval only while sync is ON. A successful save while OFF does not schedule work. Save preserves the sync preference. An already active empty test may finish. Empty tests require a separate explicit action and do not retry automatically.

Existing retained rows lock endpoint and token changes. The UI disables those fields, supplies a text reason, and uses disabled colors. The save path repeats the existing authoritative lock check under the worker mutex. No UI code mutates retained rows, attempts, or cursors. The token starts empty, is masked, opts out of saved view state and autofill, and clears after Save. Blank input keeps the saved token.
