## Applicable rules and repository decisions

Implemented means source evidence, not device execution. Web-only rules are excluded except where explicitly adapted below.

| Rule and severity | Concrete Health Bridge adaptation | Status and reason | Exact evidence symbol |

| Touch Spacing, Medium | Adapt the returned 8px guidance to Android 8dp separation through R.dimen.hb_space_sm. | implemented | `MainActivity.params` |
| Contrast Readability, High | Readable foregrounds in light and dark resource palettes. | implemented | UiTokenTest.allForegroundsPassBothThemes in app/src/test/java/dev/healthbridge/UiTokenTest.kt |
| Color Contrast, High | Minimum 4.5:1 text contrast computed from repository XML. | implemented | UiTokenTest.allForegroundsPassBothThemes in app/src/test/java/dev/healthbridge/UiTokenTest.kt |

| Error Messages, High | Native assertive live regions for validation, permission failure, and recorded test failures. Status is polite. | implemented | `MainActivity.input`, `MainActivity.showError`, `MainActivity.refresh`, `MainActivity.onCreate` |
| Progress Indicators, Medium | Recorded progress says N of M chunks. Ambiguous final acknowledgements remain a range. This is not live delivery telemetry. | implemented | `SyncStatusDisplay.progress` |
